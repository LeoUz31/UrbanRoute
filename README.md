# UrbanRoute - Redes de Transporte Multimodal

Es un sistema de optimización y análisis de redes de transporte urbano desarrollado en Java que modela estaciones, rutas y simulaciones de cierres mediante algoritmos de Dijkstra, centralidad y búsqueda en anchura. Su núcleo está construido completamente desde cero sin librerías externas de colecciones, implementando sus propias estructuras de datos (listas enlazadas, colas, tablas hash y grafos). Las únicas librerias que usa son GraphStream, los archivos de estas librerias son gs-core y gs-ui-swing.
